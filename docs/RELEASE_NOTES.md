# Bhagwa Release Notes

## Version 1.0.0 (September 6, 2026)

### Highlights
- Real-time GPS workout tracking with pace, elevation, and kilometer splits
- Saffron Bhagwa athletic Material 3 design system with AMOLED dark mode
- Custom RouteMapCanvas with speed gradient rendering
- Shareable workout flex cards with social media export
- Celebratory Independence Day card edition templates
- Google Gemini AI personalized workout coaching insights
- Export routes to GPX, GeoJSON, and KML formats
- Comprehensive unit and Robolectric test suite
- Automated GitHub Actions CI pipeline
